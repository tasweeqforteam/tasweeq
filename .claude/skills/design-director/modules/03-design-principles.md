# 03 · Design Principles as Decisions

Principles are levers. For each design, pick the **2–4 that carry the
communication objective** and let the others serve them. Trying to maximise
all of them at once produces mush.

| Principle | The decision it forces | Typical failure | Lever to fix |
|---|---|---|---|
| Visual hierarchy | What is seen 1st, 2nd, 3rd? (≤3 levels at a glance) | two elements fight for first | scale step ≥1.6×, or isolate one with space |
| Contrast | Where is the strongest difference (size, value, colour, weight, texture, density)? | contrast everywhere = contrast nowhere | spend contrast on the focal point only |
| Balance (symmetric) | Is stillness/authority right for the message? | static, dull when the message needs energy | offset one element; break symmetry with type |
| Balance (asymmetric / optical) | Do unequal masses balance across an axis? | composition "falls" to one side | counterweight with a small dense element or a saturated accent |
| Alignment | Which edges are shared? | near-misses (2–6 px) read as mistakes | align exactly or offset decisively (`qa.mjs` flags near-misses) |
| Proximity | Which items belong together? | equal spacing everywhere, so no grouping | inner spacing < outer spacing, at a clear ratio (≥1:2) |
| Repetition / rhythm | What recurs to build a system (type, rules, crops, devices)? | repetition becomes monotony | keep the structure, vary scale or crop |
| Unity & variety | What is fixed vs free in a series? | drift (no unity) or clones (no variety) | write the variation rule (module 09) |
| Proportion & scale | What are the size relationships (type scale, image:text ratio)? | arbitrary sizes | one modular scale (e.g. 1.25 / 1.333 / 1.618) |
| Emphasis | One dominant? | three "important" things | demote two of them |
| Figure–ground | Is the subject legible against its field? Is the ground itself a shape? | subject dissolves into a busy ground | value separation, a ground plane, or a shadow |
| Gestalt: closure | Can the viewer complete a shape? | over-explaining | crop or remove; let the mind finish it |
| Gestalt: similarity | What looks alike gets read as alike | unrelated items styled the same | change the style when the meaning changes |
| Gestalt: continuity | Where does the eye travel along lines and gazes? | gaze or arrow points off the canvas | direct vectors back to the message/CTA |
| Gestalt: common region | Are items grouped by an enclosing field? | boxes around everything | prefer space over boxes; box only true groups |
| Directional movement | Reading order: RTL for Arabic, LTR for Latin | Arabic layout that pulls the eye left-to-right | start the path at the reading-start edge (module 05) |
| Visual tension | Where should the composition feel charged? | tension everywhere (anxiety) or nowhere (blandness) | one deliberate near-touch, crop or tilt |
| Focal control | Is the focal point intended and isolated? | accidental focal points (logo, bright corner) | lower the contrast of the competitors |
| Information density / cognitive load | How much must be read at the viewing distance and attention budget? | a social ad set like a brochure | cut copy; move detail to caption/landing |
| Negative space | Is the empty area active (framing, tension, luxury)? | leftover gaps | see module 04 §negative space |
| Visual storytelling | Is there a before→after, problem→answer or sequence? | a static list of features | stage the reveal (carousel, scale, crop) |

## Profiles: same principles, different weights

| Brief type | Lead principles | Deliberately relaxed |
|---|---|---|
| Minimal luxury ad | negative space, scale contrast, focal control | density, variety |
| Dense editorial spread | hierarchy, alignment, rhythm, proximity | drama, tension |
| Typographic poster | scale, figure–ground, tension | literal imagery |
| Playful campaign | variety, colour contrast, movement | strict symmetry |
| Data / info layout | proximity, similarity, alignment, density control | expressive type |

Before production, write in one line which principles lead and why. After
production, critique against exactly those (module 13).
