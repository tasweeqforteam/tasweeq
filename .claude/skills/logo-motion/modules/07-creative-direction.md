# 07 · Reference-to-Creative-Direction Workflow

**Purpose:** use research to *inform* original concepts without delaying or dictating them.

1. **Analyse the logo first** (02), independently of any reference — prevents anchoring on someone else's idea.
2. **Pick the 2–3 most promising opportunities** from analysis E.
3. **Search the library** with opportunity words and facets:
   `node refs.mjs search "negative space counter reveal" --technique mask-wipe` · `node refs.mjs principles "construction circles"`.
4. **Research more only if the library is thin** for these opportunities (04). Budget: ~10 minutes / a handful of sources; stop when the evidence supports a decision.
5. **Select 2–4 high-quality references**; prefer verified entries, real videos/code/prompts.
6. **Explain relevance** of each (what problem it solved that resembles ours).
7. **Extract principles**, not sequences: timing ratios, reveal logic, how they handled geometry, transitions, QA practice.
8. **Develop three original directions** (03). The reference table at the top of `concepts.md` must show *principle borrowed*, never "copy of".
9. **Evaluate** brand relevance, originality, feasibility, production quality; **select/recommend**.
10. Continue to blueprint (08) → implementation (10) → render (12) → QA (13) → refine.

Rules: never reproduce a distinctive sequence, branded asset, or proprietary code; adapting open-source code requires checking its licence and preserving attribution (note it in the project README). New good references found along the way go into the library (`refs.mjs add`).
