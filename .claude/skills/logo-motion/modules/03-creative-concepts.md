# 03 · Creative Concept Generation

**Purpose:** three genuinely different, logo-specific directions; select or recommend one.
**Input:** completed `analysis.md` (opportunities E), relevant references (07).
**Output:** `concepts.md` (template from scaffold) with 3 directions × 11 fields + evaluation + selection.
**Done when:** each direction passes the anti-generic tests below and cites logo evidence.

## Generators — start from the logo, not from an effect
Pick three *different* generators; each yields a direction.
1. **Replay the construction** — the mark is built the way a designer would construct it (compass circles, grid lines, a single stroke), then the scaffolding disappears. Needs real construction evidence (circle parts, alignment lines).
2. **Negative space first** — the background shape is the protagonist; the logo is revealed by what is *not* there (mask enters through a counter, a hole travels into place).
3. **Relationship drama** — parts that repeat, mirror or interlock perform their relationship: attraction, orbit, docking, hand-off, call-and-response.
4. **Directional story** — the logo's dominant vector (orientation/elongation, reading direction, RTL) drives one continuous move that resolves into the mark.
5. **Typographic behaviour** — letters behave according to their script and form (Arabic kashida stretch, dots dropping in, ligature drawing as one gesture, counters opening).
6. **Transformation** — something simpler or meaningful becomes the mark (primitive → mark, one part → the next) using matched topology.
7. **Meaning metaphor** — a *verified* brand meaning expressed as behaviour (connection → parts linking; growth → organic extension). Never invent the meaning.
8. **Material behaviour** — the forms' implied physics (heavy slab lands; thin line springs; liquid fills a container shape).

Directions differ if they differ in **core idea and reveal mechanism**, not just easing, colour or duration.

## The 11 fields (per direction)
Concept name · core idea · connection to the logo (evidence) · opening visual state · main movement/transformation · reveal mechanism · transition strategy · final composition (official logo, exact) · duration & pacing · techniques & rendering · creative rationale · feasibility & limitations.

## Technique palette (options, never defaults)
| technique | fits when | avoid when |
|---|---|---|
| stroke draw-on (DrawSVG / dash) | linear parts (solidity < 0.6), continuous contours, strokes | solid blobs (draw the outline then fill only if outline is meaningful) |
| geometric construction | circles/grids measured | organic hand-drawn marks |
| mask/wipe reveal | clear direction, holes to enter through | when it would just be a generic wipe |
| assembly / modular | repetition, multiple parts, modular systems | single-part marks |
| path morph (MorphSVG) | matched topology between states | different hole counts (needs masking tricks) |
| kinetic / per-glyph type | distinctive letters; Latin letters can move independently | joined Arabic glyphs separated in final state |
| organic growth / fluid | organic forms, verified growth meaning | geometric corporate marks |
| physics, collision, magnetism | parts that interlock/attract; playful brands | luxury restraint |
| particles | brand about data, dust, stars — verified | as decoration |
| 2D→3D, camera, lighting | genuine depth idea; extrudable mark | flat brand guidelines that forbid it; when 2D says it better |
| procedural/generative | systemic identities | when determinism/fidelity is at risk |
| loops / micro | UI, loaders, avatars | broadcast idents |
| sound-driven | a sound brief exists | no audio deliverable |

## Anti-generic tests (a direction must pass all)
- **Swap test:** replace the logo with an unrelated logo — if the concept still works unchanged, reject it.
- **Evidence test:** at least two specific parts/measurements from the analysis drive the motion.
- **One-idea test:** the concept can be told in one sentence; extra effects that don't serve it are removed.
- **Final-state test:** it ends on the official logo, exactly, with a readable hold.
- **Feasibility test:** it can be built and rendered in this environment (or the limitation is stated).

## Evaluate and select
Score A/B/C (0–5) on brand relevance, originality, motion potential, feasibility; note fidelity risk. Prefer the simplest version that keeps the idea. If two are close and the choice is a matter of taste, present both briefly and recommend one; in Mode C proceed with the recommendation unless the user asked to choose.
