# 02 · Reference Analysis & Scoring

Collecting is not learning. Analyse every selected reference to extract
**decision rules** you can reuse, and label each statement:

- **[obs]**: visible in the material you actually saw
- **[doc]**: stated by the creator or the publication
- **[inf]**: your inference (e.g. "appears to sit on a 6-column grid")

If you have not seen the images (search summary only), only [doc] statements
relayed by the summary are possible. Mark them as such and do not analyse composition.

## Analysis template

```
REF-xxxx · Title · Creator · URL · status

CONCEPT       Central idea · problem solved · message · metaphor? · read in <3 s? · distinctive or generic?
ART DIRECTION Visual world · mood · lighting/material/styling control · colour logic · what makes it recognisable
LAYOUT        Grid [inf] · focal point · hierarchy steps · margins/gutters · negative-space distribution ·
              eye path (1→2→3) · which elements break the grid and why
TYPOGRAPHY    Categories (e.g. high-contrast serif display + grotesque text) · hierarchy levels · line-break control ·
              type–image interaction · Arabic/Latin handling. Name a font ONLY if [doc]
CRAFT         Image quality · crop · light/shadow consistency · perspective · edges/masking · logo fidelity ·
              type precision · integration. Strengths and visible defects
TRANSFER      Reusable principle(s), as rules · context-specific choices · DO NOT COPY list ·
              how the logic adapts to the current brief · what could be stronger
```

Write the transfer section as rules, e.g. "When the product is small and
premium, give it ≥40% clear field and let one line of display type carry the
claim." A phrase like "nice minimal vibe" teaches nothing.

## Scoring (inspected references only), out of 100

| Dimension | Max | 0–25% | 50% | 90–100% |
|---|---|---|---|---|
| Conceptual originality | 20 | stock trope | competent, familiar idea | idea you remember after one look |
| Composition & hierarchy | 20 | competing focal points | clear but generic | inevitable eye path, tension controlled |
| Typography & graphic execution | 15 | default type, bad breaks | tidy | type is part of the idea; flawless setting |
| Art direction & coherence | 15 | inconsistent world | consistent | ownable, controlled visual world |
| Communication & brand effectiveness | 15 | message unclear | message clear | message, brand and audience fused |
| Craft & production | 15 | visible artefacts | clean | no flaw at 100% zoom |

Separate indicators (not added to the score): **source credibility** · **relevance
to this brief** · **diversity contribution** · **documentation depth**.

Rules:
- The score is an internal framework, not an industry ranking. Never invent
  view counts, likes, awards or results.
- Score parts separately in your notes when a reference is strong in one
  dimension and weak in another (e.g. "use for typography only").
- If a reference scores below 50, keep it only if one dimension teaches something specific.
- `library.py` refuses scores on records that are not `inspected`.

## Selecting

Pick references because they solve **this** brief's problems. A balanced set is
usually 3–6 references, each assigned a role: *concept model*, *layout model*,
*type model*, *image-treatment model*, *campaign-system model*, *cautionary example*.
