# 16 · Open-Source Images & Visual Elements

Use free, open-licensed assets when a design needs imagery or graphic elements
the client has not supplied. **Every asset must have a known licence and source**,
logged in the design's `ASSETS.json` by `scripts/open_assets.py`.

## 1. What may be used

| Licence | Use | Credit |
|---|---|---|
| CC0 / public domain | anything, commercial included | not required (credit anyway when known) |
| MIT / ISC / Apache-2.0 (icon sets, pattern packages) | anything; keep the licence with the source files | not required in the design |
| SIL OFL (fonts) | embed and use freely; do not sell the font alone | not required |
| CC BY 4.0 | allowed with credit in the delivery note / caption | **required** |
| CC BY-SA / NC / ND, "free for personal use", unknown | **do not use** in client work | — |

**Never use as assets:** images from Pinterest (re-saves of copyrighted work),
Behance or Dribbble project images, Instagram posts, Google Images results, or
anything whose author and licence you cannot name. Those are **references to
learn from** (modules 01–02), never material to place in a design.

Extra cautions even when the licence is open: identifiable people (likeness and
publicity rights; the vendored set excludes the NASA astronaut portrait for this
reason), trademarks and logos (Simple Icons-style brand marks show the brand, they
do not license it), and agency imagery (NASA/SpaceX: no implied endorsement).

## 2. Sources available here

| Kind | Source | Command |
|---|---|---|
| Icons, 5k+ outline/filled | Tabler (MIT) | `open_assets.py icons <terms> --set tabler` |
| Icons, 1.5k × 6 weights incl. duotone | Phosphor (MIT) | `--set phosphor` |
| Icons, 1.8k outline | Lucide (ISC) | `--set lucide` |
| Repeating patterns (87) | Hero Patterns (MIT package; site states CC BY 4.0, so credit Steve Schoger) | `open_assets.py patterns` / `pattern <name>` |
| Islamic-geometric tiles | generated by `scripts/pattern.py` (original geometry) | `pattern.py star8 / rosette / kufi` |
| Photographs, textures | vendored CC0 / public-domain set (`assets/open/photos/credits.json`) | `open_assets.py photos` / `photo <name>` |
| Fonts | Alexandria, Inter Tight (OFL, bundled) | already in `templates/base.css` |

Run `open_assets.py fetch` once per session to download the icon and pattern
packages from the npm registry into `.cache/` (gitignored).

**Photo limits:** the vendored photos are small (451–1000 px wide). Use them as
insets, crops at ≤ their native width, or textures; `qa.mjs` flags upscaling. For
hero photography, use larger CC0 photos (Unsplash, Pexels, Wikimedia Commons, Openverse,
NASA). Those hosts are **blocked by this environment's network policy as of
2026-10-10**. Ask the user to allow them under the environment's network settings,
or to supply the photos.

## 3. Using icons well

- One set per design: never mix Tabler and Phosphor in one composition (different stroke logic).
- Match icon stroke to type weight: outline icons at stroke ≈ the text's stem weight; scale the stroke with icon size (`stroke-width` in the SVG).
- Size icons to the text they label (≈ cap height × 1.2–1.6), aligned to the first line's centre, never the paragraph's centre.
- Colour icons with the text colour or one accent; `copy --color` replaces `currentColor`.
- In RTL layouts the icon sits on the inline-start side (right). Mirror only directional icons (arrows, "next"), never objects (cups, clocks).

## 4. Using patterns well

- A pattern is ground, not figure: opacity 0.08–0.35 or low value contrast behind text; QA contrast measures the real pixels.
- Scale relates to the grid: tile size = a column width or a multiple of the baseline.
- Arabic and cultural work: geometric tilings (`pattern.py`) carry meaning; don't use them as generic wallpaper. Use one motif per campaign as an ownable device.

## 5. Credits in delivery

`open_assets.py credits <design-dir>` prints the attribution block. Include it in
the delivery note, and in the design itself when the licence requires it (CC BY).
